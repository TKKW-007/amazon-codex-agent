# 亚马逊 AI 运营工作台 · Codex 版

**面向亚马逊卖家的全链路 AI 运营工作流插件，覆盖选品分析、词库文案、视觉规划、广告架构与日常店铺巡检。**

本仓库提供 **亚马逊 AI 运营工作台（Codex 版）** 的官方安装包下载、使用文档及版本更新说明。

---

## 核心业务板块（S1–S5）

安装完成后，在 Codex 新建会话中输入 **「启动工作台」**，即可按需选择对应板块或从零走通全流程：

| 口令 | 板块名称 | 核心解决什么问题 |
| --- | --- | --- |
| `S1` | **S1: 选品板块** | 市场需求验证、竞品对标、1688 货源核价、利润测算与侵权合规排查（支持标准 9 步或极速报告） |
| `S2` | **S2: 文案板块** | 关键词清洗与分池、卖点映射、标题/五点/描述/后台搜索词撰写与合规核对 |
| `S3` | **S3: 视觉板块** | 主副图策划、高级 A+ 页面规划、产品短视频分镜与提示词生成 |
| `S4` | **S4: 广告板块** | 广告策略与结构搭建、广告报表诊断、Bulk 批量上传表生成与排错 |
| `S5` | **S5: 运营板块** | 支持手动报表或领星 ERP 自动取数，完成店铺日常巡检、异常诊断与待审优化建议 |
| `全链` | **S1 → S5 全链路** | 从零打造新品，按阶段顺序逐块推进并落盘交付物 |

> 说明：所有涉及第三方市场数据（Sorftime / SIF / 西柚 / 卖家精灵）、1688 与领星 ERP 的能力，均需配合您自有的服务账号与凭据使用；所有报告默认采用**深海蓝咨询白皮书风**离线 HTML 格式输出。

## 下载与安装（当前版本：1.0.0）

| 平台 | 安装包 | 解压后入口 |
| --- | --- | --- |
| **Windows** | [Amazon-Ops-Codex-1.0.0-windows.zip](https://github.com/TKKW-007/amazon-codex-agent/releases/download/v1.0.0/Amazon-Ops-Codex-1.0.0-windows.zip) | 完整解压，阅读 `00-使用说明.html`，运行 `申请授权.bat` |
| **macOS** | [Amazon-Ops-Codex-1.0.0-macos.zip](https://github.com/TKKW-007/amazon-codex-agent/releases/download/v1.0.0/Amazon-Ops-Codex-1.0.0-macos.zip) | 完整解压，阅读 `00-使用说明.html`，运行 `申请授权.command` |

> 请点击上表链接下载对应平台的 ZIP 安装包；GitHub 自动生成的 `Source code.zip` / `tar.gz` 仅含文档，不能作为安装包使用。

### 首次安装四步走
1. **准备环境**：安装并登录官方 Codex，准备 Python 3.11+ 与联网环境（Windows 需先安装 Git for Windows，详见 [安装与授权](docs/安装与授权.md)）。
2. **获取申请码**：下载对应平台 ZIP 并完整解压，运行「申请授权」生成本机申请码（macOS 如遇系统拦截，请按包内 `Mac安装指导.html` 点“仍要打开”）。
3. **提交激活**：将本机申请码发送给您的**购买服务方**，获取 **`AMZC1.`** 开头的本机授权码。
4. **完成安装**：运行「安装与更新」按提示粘贴授权码；安装完成后重启 Codex，在产品工作目录新建会话，输入 **「启动工作台」**（输入 **「检测工作台配置」** 可核对本机环境）。
